# دعوت‌نامه عروسی کوثر و محمد — Cloudflare

این پروژه یک نسخه مستقل برای Cloudflare Workers + Static Assets + D1 است.

## محتوا
- `public/index.html`: صفحه دعوت‌نامه، عکس‌های فعلی، گالری، موسیقی، شمارش معکوس با منطقه زمانی ایران، برنامه مراسم و لینک مسیریاب‌ها.
- `src/worker.js`: API ثبت پاسخ حضور، بدون نام یا شماره تماس.
- `schema.sql`: ساخت جدول پاسخ‌ها در D1.
- `wrangler.toml`: تنظیمات اولیه انتشار.

## پیش از انتشار
1. در حساب Cloudflare یک دیتابیس D1 با نام `wedding-rsvps` بسازید.
2. مقدار `database_id` در `wrangler.toml` را با شناسه واقعی دیتابیس جایگزین کنید.
3. از ریشه پروژه اجرا کنید:
   - `npx wrangler d1 execute wedding-rsvps --remote --file=./schema.sql`
   - `npx wrangler deploy`
4. دامنه یا زیردامنه دلخواه را از داشبورد Cloudflare به Worker متصل کنید.

## نکات انتقال
- فرم RSVP در نسخه جدید به D1 متصل می‌شود و اطلاعات جدید را در جدول `WeddingRSVPs` ذخیره می‌کند.
- پاسخ‌های قبلی که در مجموعه Wix با نام `WeddingRSVPs` ذخیره شده‌اند، خودکار کپی نشده‌اند؛ برای انتقال آن سوابق باید خروجی داده‌های Wix گرفته و با کنترل دسترسی در D1 وارد شود.
- تصاویر و فایل موسیقی فعلاً از نشانی‌های عمومی موجود در Wix بارگذاری می‌شوند تا فایل‌های اصلی از دست نروند. برای مهاجرت کامل رسانه‌ها، باید فایل‌های اصلی را از Wix دریافت و در Cloudflare R2 یا assets بارگذاری کرد.
- این بسته هنوز در حساب Cloudflare شما منتشر نشده است؛ برای انتشار نیاز به دسترسی/ورود به حساب Cloudflare دارید.
- قبل از عمومی کردن لینک، فرم RSVP را با یک پاسخ آزمایشی بررسی کنید و سپس رکورد آزمایشی را پاک کنید.
